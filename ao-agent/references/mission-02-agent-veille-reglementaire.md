# Mission : Agent de veille réglementaire automatisée

Client : direction juridique d'un groupe industriel.

Contexte : suivi manuel et chronophage des évolutions réglementaires sur plusieurs
juridictions, avec un risque réel de passer à côté d'un texte impactant pour
l'entreprise.

Réalisation : agent qui surveille quotidiennement plusieurs sources réglementaires,
extrait les textes pertinents, les résume, et produit une note de synthèse hebdomadaire
avec un scoring de criticité. Validation humaine obligatoire avant toute diffusion —
aucune décision n'est automatisée.

Résultat : couverture de veille plus large qu'auparavant, gain de temps significatif
pour l'équipe juridique, aucune notification envoyée sans relecture humaine préalable.

Expertises mobilisées : agents IA, collecte automatisée de données, scoring de
pertinence, gouvernance et contrôle humain.
